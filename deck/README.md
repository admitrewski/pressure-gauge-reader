# Deck
`pressure-gauge-reader.pptx` is the business presentation, built on the **Databricks brand template** (`assets/databricks_brand_template.pptx`, exported from “[BRAND TEMPLATE] Databricks Corporate Slide 2025”; 13.33 × 7.5 in, DM Sans, dark teal + Databricks red). It is generated by `build_deck.py` (python-pptx) using the template's own layouts: title, power statements, Content A, 2-column, 3-column cards, Card Right and Card Large (architecture diagram with Databricks product symbols from `assets/`).

Slides: title · outcome statement · what changes · value per persona · architecture · demo flow · governed AI · decisions & trade-offs · path to production · close.
